# OpenTime Hardware Architecture

OpenTimeのハードウェア構成を検討するための作業中の資料です。
現在の図は初期構想であり、電圧、コネクタ、通信方式などは確定していません。

## 現在決まっていること

- AC電源入力を2系統用意する
- AC/DC電源モジュールを2台搭載する
- 電源モジュールは交換可能とする
- 自作基板にCM5を2台搭載する
- 自作基板からM5Stackと7セグ表示器を接続する
- 電源モジュールの状態を監視できるようにする

## 未決定事項

- 電源モジュールの規格と製品
- 電源モジュールの出力電圧
- 電源モジュールと自作基板間のコネクタ
- Power ORingとホットスワップ制御の方式
- PSU監視インターフェース
- CM5とM5Stack間の通信方式
- 7セグ表示器の駆動方式
- GNSS受信機と信号分配回路
